# Tcapture

Windows 11 캡처 도구(Snipping Tool) 스타일의 가벼운 화면 캡처 프로그램입니다.

## 기능
- 사각형 / 창 / 전체 화면 / 자유형 캡처
- 지연 캡처 (3 / 5 / 10초)
- 전역 단축키 `Ctrl+Shift+S`, `PrtScn` (트레이 상주)
- 캡처 즉시 클립보드 복사 + `사진\Screenshots` 자동 저장
- 편집: 펜(색상), 형광펜, 지우개, 실행 취소/다시 실행, 확대/축소, 저장(PNG/JPG/BMP/GIF)
- 멀티 모니터 · Per-Monitor DPI 지원

## 빌드
Windows 기본 내장 .NET Framework 4.x 컴파일러만 있으면 됩니다.

```
build.cmd
```

`tcapture.exe`가 생성됩니다.
